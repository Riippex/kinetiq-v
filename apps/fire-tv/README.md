# Kinetiq V Fire TV

The Fire OS client is a dedicated Expo TV application backed by `react-native-tvos`. It presents remote-friendly session preparation and workout guidance; the phone remains the camera and detailed controller.

- Start Metro with `npm run dev:fire-tv` from the repository root.
- Generate the Android TV project with `npm run prebuild:fire-tv`.
- Run on an Android TV emulator or connected Fire TV with `npm run android:fire-tv`.

The generated Android directory is local build output. Verify the Leanback launcher and test the APK on Fire OS before Appstore submission.
